# 品牌资产

`fabric-avatar.svg` / `fabric-wordmark.svg` 是 Fabric 的头像与字标源文件。

**仓内没有任何代码或文档引用它们,这是正常的 —— 它们的用途在仓外**:GitHub
组织/仓库头像、npm 包页面、对外材料。这里是它们的唯一源稿。

所以别把"零引用"当成删除依据。死代码清理的判据是"没有调用方 ⇒ 不会被执行",
资产不适用这条:资产的消费者是人和外部平台,不是 import 图。两个文件合计 1.7KB,
留着的成本可以忽略,删掉的代价是丢原稿(rescue-before-delete)。

如果确认某个已经不再对外使用,删之前先把它归档到别处,不要直接 `git rm`。
